## Project Overview

**ConfoRL** is a research-grade Python library providing **provable finite-sample safety guarantees** for reinforcement learning through adaptive conformal risk control. This is the first open-source implementation combining conformal prediction theory with both offline and online RL for deployment in safety-critical domains.
